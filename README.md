# Pantau-Serangan-ddos
NETWORK DOCTOR PRO v3.0

Saya buatkan NETWORK DOCTOR PRO v3.0 dalam satu file Python, dengan fitur:
1 .Ping Analyzer.
2 .Port Scanner.
3 .Packet/Connection Analyzer sederhana.
4 .Server Health Check.
5 .DNS Lookup.
6 .Network Information.
7 .Monitoring server secara langsung.
8 .Laporan hasil pemeriksaan otomatis.
Versi ini menggunakan Python 3 dan berfokus pada pemeriksaan serta pengujian jaringan yang aman, bukan membanjiri server dengan paket DDoS.


      Fungsi setiap menu

1 .Mengukur respons ping
2 .Memeriksa port TCP umum
3 .Mencari alamat IP domain
4 .Memeriksa status HTTP website
5 .Menganalisis informasi koneksi
6 .Melihat informasi jaringan HP
7 .Memantau website 10 kali
8 .Membaca laporan pemeriksaan
Hasil pemeriksaan otomatis tersimpan di:
network_report.txt
Catatan: Gunakan port scanner dan pemeriksaan server hanya pada sistem yang kamu miliki atau sudah mendapat izin untuk mengujinya.
Langkah berikutnya kita bisa mengembangkan versi 4.0 dengan dashboard real-time, grafik latency, deteksi gangguan, dan rekomendasi perbaikan keamanan website.
